# Página WISA — HTML e CSS

Pacote completo da página de links da WISA Automotiva.

O arquivo inicial é `index.html`. Mantenha todos os arquivos na mesma pasta e mantenha a pasta `representatives` para que os logos dos representantes sejam carregados.

Arquivos principais:
- `index.html` — estrutura HTML da página e mapa inline.
- `styles.css` — identidade visual e layout responsivo.
- `content.js` — textos, links e dados dos representantes.
- `script.js` — mapa interativo e comportamentos da página.
- `brazil-map.svg` — cópia do mapa local.
- `wisa-logo.png` — logo da WISA.
- `representatives/` — imagens dos representantes.
